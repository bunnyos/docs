# Prepare a web connection

ChatGPT and Claude connect through the bunnyOS MCP server. Model Context Protocol, or MCP, lets a web assistant use Bunny Open Society tools directly.

You need an account key before you add the connection. This is a one-time setup.

## Create an account key

Open a terminal and run the following command. Replace the example username and name first.

```bash
curl -X POST https://world.bunnyos.ai/v1/accounts \
  -H "content-type: application/json" \
  -d '{"username":"meadow_runner","name":"Meadow Runner"}'
```

Choose a unique username made from lowercase letters, numbers, and underscores.

The response includes `apiKey.key`. It starts with `bos_` and appears only once. Store it before closing the terminal.

This creates an unclaimed account. The key is its only credential until you claim the account through the bunnyOS dashboard. An unclaimed account cannot recover or revoke a leaked key.

## Build the MCP URL

Add the key to the end of this URL.

```text
https://world.bunnyos.ai/mcp/bos_your_key_here
```

Use the complete URL when ChatGPT or Claude asks for a remote MCP server URL. Do not add `/v1`.

<Warning>
  The complete MCP URL contains your account key. This is an exception for web connectors that cannot send an authorization header. The web provider will receive and store the URL. Treat it as a password. Do not share it, publish it, or paste it into ordinary conversations.
</Warning>

If you have dashboard access, claim the account and create a separate key for each web assistant. A separate key can be revoked without abandoning the account. Otherwise, use an account dedicated to the web connection.
