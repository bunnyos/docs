---
title: "Inference API"
description: "Use the bunnyOS network from your own code with an OpenAI-compatible API, paid for with your Carrots."
---

If you write code, you can point it straight at the bunnyOS network. The Inference API is OpenAI-compatible, so many existing clients and SDKs work by changing the base URL and the key. Requests draw on your usage and your Carrots exactly as chatting with bunny does.

## Get a key

<Steps>
  <Step title="Go to Inference API">
    Open the [Mini App](/user/getting-started/mini-app) and tap **Inference API** under **Spend Carrots**.
  </Step>
  <Step title="Create the key">
    Give it a name if you like, then tap **Create API key**. Your `sk_` secret appears once, so copy it right away and store it somewhere safe.
  </Step>
</Steps>

Keys are listed with their name, the first few characters of the secret, and the date you made them. Tap **Revoke** next to any key to kill it. Revocation is immediate, requests using that key stop working right away.

<Warning>
The secret is shown only once. If you lose it, there is no way to see it again, revoke the key and create a new one.
</Warning>

## Your first request

Send an OpenAI-style chat completion to `https://api.bunnyos.ai/v1/inference/chat/completions`, with your key as a bearer token.

```bash
curl https://api.bunnyos.ai/v1/inference/chat/completions \
  -H "Authorization: Bearer sk_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemma-4-e4b",
    "stream": true,
    "messages": [{"role":"user","content":"hi"}]
  }'
```

Set `"stream": false` if you would rather get the whole answer in one response.

## Models

| Model | Context |
| --- | --- |
| `gemma-4-e4b` | 128K |
| `qwen3.7-flash` | 128K |

Each model has its own flat Carrot price per request, and the bigger model costs more. A `GET` request to `/v1/inference/models` lists the available models, in the same shape an OpenAI client expects.

## What a request costs

Pricing works exactly as it does in chat. You pay a flat price per request whatever the length of the prompt or the answer, and failed requests are refunded automatically. Spending follows the same order as chat too. See [Carrots and OS explained](/user/carrots/explained) for the full picture.

<Note>
There is no balance endpoint in the API. Check your balance, your history, and your usage on the **Carrots Balance** and **Usage** screens of the Mini App, where API requests appear as **Inference** entries alongside your chats.
</Note>
