---
title: "The Mini App"
description: "The bunnyOS control panel that opens inside Telegram, where you check balances, manage services, earn Carrots, and spend them."
---

Chatting with bunny happens in the chat. Everything else lives in the Mini App, a small control panel that opens right inside Telegram. It is where you check your Carrot balance, tidy up what bunny remembers, subscribe to bunny pro, stake `$OS`, supply compute, and create API keys.

## Open it

<Steps>
  <Step title="Open your chat with bunny">
    Go to your private chat with [@bunnyagentbot](https://t.me/bunnyagentbot).
  </Step>
  <Step title="Send /app">
    bunny replies with an **Open bunnyOS app** button. Tap it and the panel opens over the chat.
  </Step>
  <Step title="Or use the button on /start">
    The `/start` greeting carries the same **Open bunnyOS app** button, so you can open it from there too.
  </Step>
</Steps>

The Mini App works in private chats only, so sending `/app` in a group gets you pointed back to a direct message. It also opens only from inside Telegram, not in a normal browser.

## The menu

The home screen shows your Telegram profile at the top, then five sections. Rows in **Services** show a count on the right, so you can see at a glance how much is in each one.

### Manage

| Row | What it does |
| --- | --- |
| **Carrots Balance** | Your current balance plus your full activity history. See [Your Carrots and usage](/user/carrots/your-carrots). |
| **Usage** | How much of your free usage and pro usage you have spent, and when each resets. |
| bunny pro | Shows **Get pro for \$9** when you are not subscribed. Once you are subscribed it shows the date your subscription runs until. See [bunny pro](/user/carrots/bunny-pro). |

### Services

| Row | What it does |
| --- | --- |
| **Automations** | Add, edit, and delete the tasks bunny runs on a schedule. See [Calendar and automations](/user/chat/calendar-and-automations). |
| **Calendar** | Your agenda of events, reminders, and automations, plus connected Google accounts. See [Calendar and automations](/user/chat/calendar-and-automations). |
| **Inbox** | Recent mail from connected email accounts. See [Connected apps](/user/chat/connected-apps). |
| **Web Search** | A history of every live web search bunny has run for you. See [What bunny can do](/user/chat/built-in-tools). |
| **Memory** | Search what bunny remembers about you, delete single facts, or clear everything. See [Memory](/user/chat/memory). |
| **Lists** | The shareable recommendation lists bunny has made for you. Open one or forward the link. |

### Earn Carrots

| Row | What it does |
| --- | --- |
| **Stake \$OS** | Connect a wallet on Base and stake `$OS` for a daily Carrot stream. See [Stake OS](/user/carrots/stake-os). |
| **Supply Compute** | Register a worker so your machine can answer requests for the network. See [Contribute compute](/user/compute/overview). |
| **Complete Tasks** | Coming soon. |

### Spend Carrots

| Row | What it does |
| --- | --- |
| **Inference API** | Create and revoke API keys so your own code can use the network. See [Inference API](/user/developer/inference-api). |
| **bunnyApps** | Coming soon. |

### Community

| Row | What it does |
| --- | --- |
| **Network Stats** | Live counts of workers online per model, plus all-time network totals. These are network-wide numbers, not yours. |
| **Generate Content** | Opens **Bunny Images**, where you describe a scene and get a picture of the bunny mascot. |

Every screen you open from here has a **Back** button in the top left that returns you to the menu.

<Note>
The Mini App may ask for your location when it opens. bunny uses it only to keep "near me" searches accurate, so that asking for a good coffee shop nearby returns places that are actually nearby.
</Note>

## Terms and privacy

Links to the Terms and the Privacy policy sit in the footer of the home screen. Tapping either opens it in a new tab.
